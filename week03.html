Data Dinamis: Dictionaries

Apa itu dictionary?

Dictionary adalah salah satu tipe data komposit Python; seperti list, ia dapat menyimpan koleksi data. Dictionary juga dikenal sebagai associative array: kumpulan pasangan key–value yang ditulis di dalam kurung kurawal { }.

d = {
    <key>: <value>,
    <key>: <value>,
    ...
    <key>: <value>
}
Catatan: ini hanya notasi, bukan kode yang bisa dijalankan: <key> dan <value> adalah placeholder.

Dictionary yang memetakan kota Major League Baseball ke timnya, dipakai di seluruh halaman ini:

MLB_team = {
    'Colorado' : 'Rockies',
    'Boston'   : 'Red Sox',
    'Minnesota': 'Twins',
    'Milwaukee': 'Brewers',
    'Seattle'  : 'Mariners'
}

Dictionary vs. list, sekilas

Keduanya mutable, ukurannya dinamis, dan keduanya bisa bersarang: list bisa berisi sub-list dan dictionary bisa berisi dictionary lain; keduanya juga bisa saling menampung, dictionary bisa berisi list dan list bisa berisi dictionary. Perbedaan sebenarnya ada pada cara mengakses elemen: list memakai indeks yang menandai posisi, dictionary memakai key yang menandai asosiasi. Sisa halaman ini sebagian besar membahas akibat dari satu perbedaan itu.

Membuat dictionary

Selain menulis literal langsung, dict() membuat dictionary dari urutan pasangan key–value:

Dari list berisi tuple

MLB_team = dict([
    ('Colorado', 'Rockies'),
    ('Boston', 'Red Sox'),
    ('Minnesota', 'Twins'),
    ('Milwaukee', 'Brewers'),
    ('Seattle', 'Mariners')
])
print(MLB_team)
Lihat hasil 
{'Colorado': 'Rockies', 'Boston': 'Red Sox', 'Minnesota': 'Twins', 'Milwaukee': 'Brewers', 'Seattle': 'Mariners'}

Dengan keyword argument (hanya bisa kalau setiap key berupa string yang bentuknya seperti identifier biasa)

MLB_team = dict(
    Colorado='Rockies',
    Boston='Red Sox',
    Minnesota='Twins',
    Milwaukee='Brewers',
    Seattle='Mariners'
)
print(type(MLB_team))
Lihat hasil 
<class 'dict'>

Mengakses isi: key, bukan indeks

Entri muncul sesuai urutan penulisannya (dictionary menyimpan urutan penyisipan sejak Python 3.7), tetapi kamu tetap tidak bisa mengakses item lewat indeks posisi seperti pada list:

Salah — diperlakukan seperti list 
>>> MLB_team[1]

KeyError: 1. Tidak ada key 1 di dictionary ini.

Benar — key yang ada 
>>> MLB_team['Minnesota']
'Twins'
>>> MLB_team['Colorado']
'Rockies'
Sintaks benar, key tidak terdefinisi 
>>> MLB_team['Toronto']

KeyError: 'Toronto'. Caranya sudah benar, hanya saja key ini memang tidak ada.

Kotak pink dan kotak amber sama-sama memunculkan KeyError, tetapi dengan alasan berbeda: contoh pink memakai pendekatan yang salah sama sekali (mengindeks seperti list), sedangkan contoh amber memakai pendekatan yang benar pada key yang memang tidak ada. Perbedaan ini penting dipegang karena perbaikannya berbeda tiap kali (pakai key, atau periksa dulu bahwa key itu ada).

Menambah, mengubah, menghapus

Isi key baru untuk menambah entri, isi key yang sudah ada untuk mengubahnya:

MLB_team['Kansas City'] = 'Royals'
print(MLB_team)
Lihat hasil 
{'Colorado': 'Rockies', 'Boston': 'Red Sox', 'Minnesota': 'Twins', 'Milwaukee': 'Brewers', 'Seattle': 'Mariners', 'Kansas City': 'Royals'}

Key baru ditambahkan di bagian akhir, sesuai urutan penyisipan.

Sintaks sama, tapi key-nya sudah ada

MLB_team['Seattle'] = 'Seahawks'
print(MLB_team)
Lihat hasil 
{'Colorado': 'Rockies', 'Boston': 'Red Sox', 'Minnesota': 'Twins', 'Milwaukee': 'Brewers', 'Seattle': 'Seahawks', 'Kansas City': 'Royals'}

'Seattle' tetap di posisi semula; hanya value-nya yang berubah.

Hapus entri dengan del dan key-nya:

del MLB_team['Seattle']
print(MLB_team)
Lihat hasil 
{'Colorado': 'Rockies', 'Boston': 'Red Sox', 'Minnesota': 'Twins', 'Milwaukee': 'Brewers', 'Kansas City': 'Royals'}

Batasan

Value pada dictionary boleh bertipe apa saja dan boleh berulang; untuk key, ceritanya berbeda.

1. Sebuah key hanya boleh muncul sekali

Kedua kotak ini tidak menyebabkan crash, tetapi memperlihatkan jebakan yang sama dengan dua cara: menulis key yang sama lagi tidak pernah membuat entri kedua, melainkan diam-diam menimpa yang pertama.

Hati-hati — menimpa setelah dibuat 
MLB_team = {'Colorado': 'Rockies', 'Boston': 'Red Sox',
            'Minnesota': 'Twins', 'Milwaukee': 'Brewers',
            'Seattle': 'Mariners'}
MLB_team['Minnesota'] = 'Timberwolves'
MLB_team

'Minnesota' kini dipetakan ke 'Timberwolves', tetap satu entri.

Hati-hati — terduplikasi di dalam satu literal 
MLB_team = {'Colorado': 'Rockies', 'Boston': 'Red Sox',
            'Minnesota': 'Twins', 'Milwaukee': 'Brewers',
            'Seattle': 'Mariners', 'Minnesota': 'Twins'}
MLB_team

Python hanya menyimpan 'Minnesota' yang terakhir: tetap 5 key, bukan 6.

2. Key sebaiknya bertipe immutable (hashable)

Integer, float, string, boolean, dan tuple bisa dipakai sebagai key. List tidak bisa, karena list itu mutable.

Key tuple bisa 
d = {(1, 1): 'a', (1, 2): 'b', (2, 1): 'c', (2, 2): 'd'}
d[(1,1)]
d[(2,1)]

Hasilnya: 'a', lalu 'c'.

Key list tidak bisa 
d = {[1, 1]: 'a', [1, 2]: 'b', [2, 1]: 'c', [2, 2]: 'd'}

TypeError: unhashable type: 'list'

3. Value boleh berulang bebas

d = {0: 'a', 1: 'a', 2: 'a', 3: 'a'}
print(d)
print(d[0] == d[1] == d[2])
Lihat hasil 
{0: 'a', 1: 'a', 2: 'a', 3: 'a'}
True

Key yang kebetulan berupa integer tetaplah key, bukan posisi

Salah — diperlakukan seperti list 
MLB_team['Toronto']
MLB_team[1]

Keduanya memunculkan KeyError: masing-masing karena key tidak terdefinisi dan karena indeks numerik.

0, 1, 2, 3 ini adalah key, bukan indeks 
d = {0: 'a', 1: 'b', 2: 'c', 3: 'd'}
d
d[0]
d[2]

Bisa jalan, tapi hanya karena 0 dan 2 memang benar-benar key di d.

Membalik urutan penulisan pasangan tidak mengubah hasil pencarian; posisi sebuah key tidak pernah menentukan, hanya pasangan key–value-nya:

d = {3: 'd', 2: 'c', 1: 'b', 0: 'a'}
print(d)
print(d[0])
print(d[2])
Lihat hasil 
{3: 'd', 2: 'c', 1: 'b', 0: 'a'}
a
c

Jawabannya sama seperti sebelumnya, walaupun urutan pasangannya dibalik.

Dictionary bukan list

Meski sintaksnya tampak mirip, dictionary tidak punya satu pun operasi posisional milik list:

Ketiganya gagal 
d = {3: 'd', 2: 'c', 1: 'b', 0: 'a'}
type(d)
d[-1]
d[0:2]
d.append('e')

type(d) adalah <class 'dict'>. Lalu: d[-1] → KeyError: -1 (tidak ada key -1 di sini; indeks negatif adalah konsep list/string); d[0:2] → TypeError: unhashable type: 'slice' (slicing butuh posisi, sedangkan dictionary tidak punya); d.append('e') → AttributeError: 'dict' object has no attribute 'append' (dictionary bertambah lewat key, bukan append).

Membangun langkah demi langkah

Mulai dari dictionary kosong dan isi satu key demi satu key, berguna kalau datanya tidak datang sekaligus:

person = {}
print(type(person))

person['fname'] = 'Joe'
person['lname'] = 'Fonebone'
person['age'] = 51
person['spouse'] = 'Edna'
person['children'] = ['Ralph', 'Betty', 'Joey']
person['pets'] = {'dog': 'Fido', 'cat': 'Sox'}
print(person)
Lihat hasil 
<class 'dict'>
{'fname': 'Joe', 'lname': 'Fonebone', 'age': 51, 'spouse': 'Edna', 'children': ['Ralph', 'Betty', 'Joey'], 'pets': {'dog': 'Fido', 'cat': 'Sox'}}

Value bisa berupa list, bahkan dictionary lain, karena dictionary bisa bersarang seperti list.

Masuk ke value bersarang dengan menambahkan indeks atau key lain di ujungnya:

print(person['children'][-1])
print(person['pets']['cat'])
Lihat hasil 
Joey
Sox

person['children'] adalah list, jadi [-1] adalah indeks list; person['pets'] adalah dictionary, jadi ['cat'] adalah key-nya.

Key dan value boleh bercampur tipe

foo = {42: 'aaa', 2.78: 'bbb', True: 'ccc'}
print(foo)
print(foo[42])
print(foo[2.78])
print(foo[True])
Lihat hasil 
{42: 'aaa', 2.78: 'bbb', True: 'ccc'}
aaa
bbb
ccc

Satu dictionary, tiga tipe key berbeda (int, float, bool) dan satu value per key, semuanya sah karena ketiga tipe itu hashable.

Bahkan objek tipe atau fungsi bawaan bisa jadi key, karena keduanya juga hashable:

d = {int: 1, float: 2, bool: 3}
print(d)
print(d[float])

d = {bin: 1, hex: 2, oct: 3}
print(d[oct])
Lihat hasil 
{<class 'int'>: 1, <class 'float'>: 2, <class 'bool'>: 3}
2
3

Operators: in, not in, len

Operator keanggotaan dan ukuran yang sudah dikenal pada string, list, dan tuple juga bekerja pada dictionary, tepatnya pada key-nya:

MLB_team = {'Colorado': 'Rockies', 'Boston': 'Red Sox',
            'Minnesota': 'Twins', 'Milwaukee': 'Brewers',
            'Seattle': 'Mariners'}
print('Milwaukee' in MLB_team)
print('Toronto' in MLB_team)
print('Toronto' not in MLB_team)
Lihat hasil 
True
False
True
Pola aman yang layak dipakai 
'Toronto' in MLB_team and MLB_team['Toronto']

Hasilnya False, bukan error: and berhenti lebih awal (short-circuit), jadi MLB_team['Toronto'] tidak pernah dijalankan begitu pemeriksaan keanggotaan gagal. Ini ide yang sama dengan Bagian C dan D pada tugas, hanya ditulis dengan in alih-alih .get().

print(len(MLB_team))
Lihat hasil 
5

d = {'a': 10, 'b': 20, 'c': 30}

20
['a', 'b', 'c']

Tiap item adalah tuple (key, value), jadi [1][0] adalah key pasangan kedua dan [1][1] adalah value-nya.

d.values(): tidak dihapus duplikatnya

d = {'a': 10, 'b': 20, 'c': 30}
print(list(d.values()))

d = {'a': 10, 'b': 10, 'c': 10}
print(list(d.values()))
Lihat hasil 
[10, 20, 30]
[10, 10, 10]

Value yang berulang tetap berulang; tidak seperti key, value tidak harus unik (Batasan 3 di atas).

d.pop()

d = {'a': 10, 'b': 20, 'c': 30}
print(d.pop('b'))
print(d)
Lihat hasil 
20
{'a': 10, 'c': 30}

pop() mengembalikan value yang dihapus, bukan seluruh dictionary.

Key tidak ada, tanpa default 
d = {'a': 10, 'b': 20, 'c': 30}
d.pop('z')

KeyError: 'z'

Key tidak ada, dengan default 
d = {'a': 10, 'b': 20, 'c': 30}
d.pop('z', -1)

Mengembalikan -1, tanpa crash, ide yang sama dengan .get().

d.popitem(): selalu menghapus pasangan yang paling baru ditambahkan

d = {'a': 10, 'b': 20, 'c': 30}
print(d.popitem())
print(d)
print(d.popitem())
print(d)
print(d.popitem())
print(d)
Lihat hasil 
('c', 30)
{'a': 10, 'b': 20}
('b', 20)
{'a': 10}
('a', 10)
{}

Tiap pemanggilan mengambil satu pasangan dari ujung, yang paling baru disisipkan lebih dulu.

d.popitem() pada dictionary yang sudah kosong

d = {}
d.popitem()
Lihat hasil 
KeyError: 'popitem(): dictionary is empty'

d.update(): tiga cara setara untuk menggabungkan {'b': 200, 'd': 400}

d1 = {'a': 10, 'b': 20, 'c': 30}
d2 = {'b': 200, 'd': 400}
d1.update(d2)
print(d1)

d1 = {'a': 10, 'b': 20, 'c': 30}
d1.update([('b', 200), ('d', 400)])
print(d1)

d1 = {'a': 10, 'b': 20, 'c': 30}
d1.update(b=200, d=400)
print(d1)
Lihat hasil 
{'a': 10, 'b': 200, 'c': 30, 'd': 400}
{'a': 10, 'b': 200, 'c': 30, 'd': 400}
{'a': 10, 'b': 200, 'c': 30, 'd': 400}

Ketiga pemanggilan menghasilkan hasil yang persis sama: key yang sudah ada ('b') ditimpa, key baru ('d') ditambahkan.

Mengurutkan dictionary

Dictionary tidak punya urutan bawaan yang bisa disusun ulang. Sebagai gantinya, urutkan .items() lalu bangun dictionary baru dari hasilnya. Mengurutkan berdasarkan key adalah perilaku bawaan; berdasarkan value perlu key=lambda, persis seperti pada list:

people = {3: 'Jim', 2: 'Jack', 4: 'Jane', 1: 'Jill'}

# Urutkan berdasarkan key
print(dict(sorted(people.items())))

# Urutkan berdasarkan value
print(dict(sorted(people.items(), key=lambda item: item[1])))
Lihat hasil 
{1: 'Jill', 2: 'Jack', 3: 'Jim', 4: 'Jane'}
{2: 'Jack', 4: 'Jane', 1: 'Jill', 3: 'Jim'}

item adalah tuple (key, value), jadi item[1] mengurutkan berdasarkan value; [0][0] atau [-1][0] pada list hasil urutan lalu memberi key dengan value terkecil atau terbesar tanpa membangun seluruh dictionary terurut, persis trik yang dipakai cheapest_product/priciest_product pada tugas.

Dictionary vs. list

ListDictionary
Punya urutan (ordered)Urutan penyisipan tetap terjaga (Python 3.7+), tetapi tidak ada urutan posisional untuk diindeks
Menyimpan data secara linear, tiap item mendapat indeks numerikMenyimpan data sebagai pasangan key–value, tiap key dipetakan ke satu value
Akses dan ubah lewat indeksAkses lewat key
Lebih cepat mengakses item lewat indeksLebih cepat mencari item lewat key yang cocok
