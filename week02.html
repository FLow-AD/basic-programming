Data Dinamis: List & Tuple

Struktur data yang bisa menyimpan sejumlah data sekaligus — list yang bisa diubah, dan tuple yang tidak.

Struktur data

Struktur data adalah struktur yang dapat menyimpan sejumlah data sekaligus. Python punya empat jenis bawaan: list, tuple, dictionary, dan set. Minggu ini fokus ke dua yang pertama; dictionary dan set menyusul di Minggu 3 dan 4.

Apa itu list?

List menyimpan koleksi item yang berurutan, ditulis di antara kurung siku [ ] dengan item dipisah koma. Karena isinya bisa ditambah, dihapus, atau diubah setelah dibuat, list disebut bertipe mutable.

# Daftar belanja
shoplist = ['apple', 'mango', 'carrot', 'banana']

Karakteristik list

  • Memiliki urutan (ordered) — urutan yang sama isinya, jika urutannya beda, dianggap list yang berbeda.
  • Bisa menyimpan objek apa pun, boleh campuran tipe, dan boleh berisi objek yang berulang.
  • Elemen diakses lewat indeks, dimulai dari 0 seperti pada string.
  • Bisa bersarang (list di dalam list) sedalam apa pun.
  • Bersifat mutable dan dinamis (ukurannya bisa berubah).

Indexing & slicing

a = ['foo', 'bar', 'baz', 'qux', 'quux', 'corge'] — tebak dulu, lalu klik untuk lihat hasil

a = ['foo', 'bar', 'baz', 'qux', 'quux', 'corge']
print(a[0], a[2], a[5])
print(a[-1], a[-2], a[-5])
Lihat hasil 
foo baz corge
corge quux bar

Indeks negatif dihitung dari belakang: a[-1] adalah elemen terakhir.

a[m:n] memberikan sebagian a dari indeks m sampai n (tidak termasuk n).

Tebak dulu, lalu klik untuk lihat hasil

a = ['foo', 'bar', 'baz', 'qux', 'quux', 'corge']
print(a[2:5])
print(a[-5:-2])
print(a[1:4])
print(a[-5:-2] == a[1:4])
print(a[:4] + a[4:] == a)
Lihat hasil 
['baz', 'qux', 'quux']
['bar', 'baz', 'qux']
['bar', 'baz', 'qux']
True
True

Slice dengan indeks positif dan negatif bisa saling bertemu di elemen yang sama; a[:4] + a[4:] selalu menyusun ulang seluruh list.

Bagian ketiga a[awal:akhir:langkah] mengatur stride (interval). Langkah negatif membalik arah.

b = list(range(10)) — tebak dulu, lalu klik untuk lihat hasil

b = list(range(10))
print(b[0:6:2])
print(b[1:6:2])
print(b[6:0:-2])
Lihat hasil 
[0, 2, 4]
[1, 3, 5]
[6, 4, 2]

Syntax [::-1] membalik urutan — berlaku sama untuk list maupun string. Tapi a[:] (tanpa -1) berperilaku beda antara keduanya:

Tebak dulu, lalu klik untuk lihat hasil

a = ['foo', 'bar', 'baz', 'qux', 'quux', 'corge']
print(a[::-1])
s = 'foobar'
print(s[:] is s)
print(a[:] is a)
Lihat hasil 
['corge', 'quux', 'qux', 'baz', 'bar', 'foo']
True
False
Diperbaiki dari slide asli: slide menulis bahwa [:] pada string “akan memberikan list itu sendiri”. Yang dimaksud adalah string itu sendiri (s[:] is s bernilai True karena string immutable). Pada list, a[:] justru membuat salinan baru, sehingga a[:] is a bernilai False.

Operator & fungsi pada list

Tebak dulu, lalu klik untuk lihat hasil

a = ['foo', 'bar', 'baz', 'qux', 'quux', 'corge']
print('qux' in a, 'thud' not in a)
print(a + ['grault', 'garply'])
print(a * 2)
print(len(a), min([4, 1, 7]), max([4, 1, 7]))
Lihat hasil 
True True
['foo', 'bar', 'baz', 'qux', 'quux', 'corge', 'grault', 'garply']
['foo', 'bar', 'baz', 'qux', 'quux', 'corge', 'foo', 'bar', 'baz', 'qux', 'quux', 'corge']
6 1 7

Operasi ini juga bisa langsung dikenakan pada literal list tanpa menyimpannya ke variabel dulu, misalnya ['foo', 'bar', 'baz'][2] atau len(['a', 'b', 'c'][::-1]).

List bersarang

Sebuah list bisa memuat sublist, dan sublist itu bisa memuat sub-sublist, sedalam apa pun.

x = ['a', ['bb', ['ccc', 'ddd'], 'ee', 'ff'], 'g', ['hh', 'ii'], 'j'] — tebak dulu, lalu klik untuk lihat hasil

x = ['a', ['bb', ['ccc', 'ddd'], 'ee', 'ff'], 'g', ['hh', 'ii'], 'j']
print(len(x))
print(x[1][1][0])
Lihat hasil 
5
ccc

Operator dan fungsi hanya berlaku pada level list yang dimaksud, tidak recursive: x punya 5 elemen (3 string dan 2 sublist) — isi di dalam sublist tidak ikut dihitung oleh len(x). Untuk masuk ke sublist, tambahkan indeks lagi: x[1] lalu x[1][1] lalu x[1][1][0].

Operator in pada list bersarang — tebak dulu, lalu klik untuk lihat hasil

print('ddd' in x)
print('ddd' in x[1])
print('ddd' in x[1][1])
Lihat hasil 
False
False
True

'ddd' hanya “terlihat” pada level tempat ia benar-benar berada, yaitu x[1][1].

Mengubah list

Karena list mutable, isinya bisa diganti lewat indexing dan penugasan biasa — berbeda dari string yang akan menghasilkan error jika dicoba dengan cara yang sama.

Tebak dulu, lalu klik untuk lihat hasil

a = ['foo', 'bar', 'baz', 'qux', 'quux', 'corge']
a[2] = 10
print(a)
del a[3]
print(a)
a[1:3] = [1.1, 2.2, 3.3]
print(a)
Lihat hasil 
['foo', 'bar', 10, 'qux', 'quux', 'corge']
['foo', 'bar', 10, 'quux', 'corge']
['foo', 1.1, 2.2, 3.3, 'quux', 'corge']

Menugaskan ke sebuah slice (a[1:3] = [...]) bisa mengganti beberapa elemen sekaligus dengan jumlah elemen baru yang berbeda — ini juga cara menyisipkan (a[2:2] = [...]) atau menghapus banyak elemen (a[1:5] = []) tanpa del.

Menambah satu elemen di akhir memakai += memerlukan iterable di sisi kanan — sebuah angka saja bukan iterable.

Tebak dulu, lalu klik untuk lihat hasil

a = ['foo', 'bar', 'baz']
try:
    a += 3.14
except TypeError as e:
    print('TypeError:', e)
a += [3.14]
print(a)
Lihat hasil 
TypeError: 'float' object is not iterable
['foo', 'bar', 'baz', 3.14]
Diperbaiki dari slide asli: slide menunjukkan a += 20 gagal tanpa menandainya sebagai error, sementara slide sesudahnya (“Sifat dinamis list”) memakai a += 3.14 seolah berhasil. Keduanya sama-sama menghasilkan TypeError; untuk menambah satu elemen, bungkus dalam list satu elemen (singleton list): a += [3.14].

Jebakan lain: string bukan singleton

Karena string adalah iterable berisi karakter, a += 'baz' bukan menambah satu elemen 'baz', melainkan menambah tiga elemen: 'b', 'a', 'z'. Selalu bungkus dengan [...] jika ingin menambah satu item apa pun jenisnya: a += ['baz'].

Alias vs salinan

List adalah objek, dan sebuah variabel hanyalah nama yang menunjuk ke objek itu. b = a tidak membuat list baru — b dan a menjadi dua nama untuk satu list yang sama (disebut alias). Untuk mendapat list baru yang independen, gunakan a.copy() atau a[:].

Tebak dulu, lalu klik untuk lihat hasil

a = [1, 2, 3]
b = a
c = a.copy()
d = a[:]
b.append(4)
print('a:', a)
print('b is a:', b is a)
print('c is a:', c is a, 'c:', c)
print('d is a:', d is a, 'd:', d)
Lihat hasil 
a: [1, 2, 3, 4]
b is a: True
c is a: False c: [1, 2, 3]
d is a: False d: [1, 2, 3]

Mengubah b ikut mengubah a, karena keduanya list yang sama. c dan d tidak ikut berubah karena keduanya salinan independen. Ini bukan bagian dari slide asli — ditambahkan karena ini salah satu sumber bug paling umum bagi pemula.

Metode list

a = ['a', 'b']

list.extend(iterable)a.extend([1, 2, 3])['a', 'b', 1, 2, 3]

list.remove(obj)a.remove('a')[3.14, 'b']
list.pop(index=-1)a.pop() atau a.pop(0)Mengembalikan & menghapus elemen pada index (indeks terakhir jika kosong)

Diperbaiki dari slide asli: slide menulis a.pop(index=-1) seolah bisa dipanggil dengan keyword argument. Faktanya list.pop() hanya menerima argumen posisi — a.pop(index=-1) menghasilkan TypeError: list.pop() takes no keyword arguments. Tulis a.pop() atau a.pop(0).

Jebakan: sort() mengembalikan None

r = s.sort() membuat r bernilai None, karena sort() mengurutkan s di tempat (in place) dan tidak mengembalikan apa pun. Jika ingin list terurut baru tanpa mengubah aslinya, gunakan fungsi bawaan sorted(s) yang mengembalikan list baru.

Sifat dinamis list terlihat dari ukurannya yang bisa berubah kapan pun dibutuhkan — bertambah lewat append/extend/insert/penugasan slice, berkurang lewat remove/pop/del/penugasan slice kosong.

Tuple

Tuple mirip list, dengan dua perbedaan utama: ditandai kurung lengkung ( ) (bukan siku), dan bersifat immutable — setelah dibuat, isinya tidak bisa diubah.

Tebak dulu, lalu klik untuk lihat hasil

t = ('foo', 'bar', 'baz', 'qux', 'quux', 'corge')
print(t)
print(t[0], t[-1], t[1::2])
Lihat hasil 
('foo', 'bar', 'baz', 'qux', 'quux', 'corge')
foo corge ('bar', 'qux', 'corge')

Indexing, slicing, dan stride bekerja sama seperti pada list.

Tebak dulu, lalu klik untuk lihat hasil

t = ('foo', 'bar')
try:
    t[0] = 'Bark'
except TypeError as e:
    print('TypeError:', e)
Lihat hasil 
TypeError: 'tuple' object does not support item assignment

Menukar nilai dua variabel

Cara klasik memakai variabel sementara:

temp = a
a = b
b = temp

Karena Python bisa mengemas beberapa nilai jadi tuple (packing) dan membongkarnya kembali ke beberapa variabel sekaligus (unpacking) dalam satu pernyataan, cara ini bisa disingkat jadi satu baris tanpa variabel sementara:

Tebak dulu, lalu klik untuk lihat hasil

a, b = 'foo', 'bar'
print(a, b)
a, b = b, a
print(a, b)
Lihat hasil 
foo bar
bar foo

Sisi kanan b, a dikemas jadi tuple ('bar', 'foo') terlebih dulu, baru dibongkar ke a dan b — sehingga nilai lama keduanya tetap terpakai secara bersamaan, tanpa perlu variabel sementara.

Kapan tuple lebih baik daripada list?

  • Eksekusi program dengan tuple sedikit lebih cepat daripada list yang setara.
  • Untuk data yang memang dimaksudkan tidak bisa diubah (misalnya koordinat, atau data yang dibagi ke banyak bagian program dan tidak boleh diubah tanpa sengaja).
  • Sebagai key dictionary — dictionary mensyaratkan key bertipe immutable, sehingga tuple bisa dipakai (list tidak bisa).

Hal unik saat mencetak tuple

Python menganggap beberapa nilai yang dipisah koma sebagai tuple, bahkan tanpa kurung eksplisit.

Tebak dulu, lalu klik untuk lihat hasil

a = 'foo'
b = 42
print(a, 3.14159, b)
x = a, 3.14159, b
print(x, type(x))
Lihat hasil 
foo 3.14159 42
('foo', 3.14159, 42) <class 'tuple'>

Tebak dulu, lalu klik untuk lihat hasil

t = (2)
print(type(t))
t = (2,)
print(type(t), t)
Lihat hasil 
<class 'int'>
<class 'tuple'> (2,)

Yang membuat sesuatu jadi tuple adalah koma, bukan tanda kurung. (2) hanya angka 2 di dalam kurung biasa; tuple satu elemen wajib memakai koma penutup, (2,).

Packing & unpacking

Packing: beberapa nilai dikemas jadi satu tuple. Unpacking: sebuah tuple dibongkar ke beberapa variabel sekaligus — jumlah variabel di kiri harus sama persis dengan jumlah elemen tuple.

Tebak dulu, lalu klik untuk lihat hasil

t = ('foo', 'bar', 'baz', 'qux')
s1, s2, s3, s4 = t
print(s1, s2, s3, s4)
Lihat hasil 
foo bar baz qux

Tebak dulu, lalu klik untuk lihat hasil

t = ('foo', 'bar', 'baz', 'qux')
s1, s2, s3 = t
Lihat hasil 
ValueError: too many values to unpack (expected 3)

Tebak dulu, lalu klik untuk lihat hasil

t = ('foo', 'bar', 'baz', 'qux')
s1, s2, s3, s4, s5 = t
Lihat hasil 
ValueError: not enough values to unpack (expected 5, got 4)
