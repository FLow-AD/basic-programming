Pernyataan Bersyarat: Conditional Statements

if, elif, dan else mengubah alur program berdasarkan evaluasi Boolean, sebuah blok didefinisikan lewat indentasi, ekspresi bersyarat (ternary) memampatkan if/else menjadi satu ekspresi, dan pass jadi placeholder ketika suatu blok memang harus kosong.

  5. Ekspresi bersyarat (ternary operator)
  6. Pernyataan pass

Pengenalan if statement

Bentuk paling sederhana dari pernyataan bersyarat adalah sebagai berikut:

if <expr>:
    <statement>
Catatan: ini notasi, bukan kode yang bisa dijalankan langsung — <expr> dan <statement> adalah placeholder.
  • <expr> adalah ekspresi yang dievaluasi dalam konteks Boolean (bernilai True/False).
  • <statement> adalah pernyataan Python yang valid, dan harus ditulis menjorok ke dalam (indented).

Jika <expr> benar, <statement> dieksekusi. Jika <expr> salah, <statement> diabaikan. Nilai <expr> tidak harus bool secara harfiah — nilai apa pun dievaluasi lewat “kebenaran”-nya (truthiness): 0, string kosong, dan koleksi kosong bernilai falsy; selainnya truthy.

Tebak dulu (truthy/falsy), lalu klik untuk lihat hasil

x = 0
y = 5

if x < y:      # Truthy
    print('yes')

if y < x:      # Falsy
    print('yes')

if x:          # Falsy
    print('yes')

if y:          # Truthy
    print('yes')

if x or y:                    # Truthy
    print('yes')

if x and y:                   # Falsy
    print('yes')

if 'aul' in 'grault':         # Truthy
    print('yes')

if 'quux' in ['foo', 'bar', 'baz']:  # Falsy
    print('yes')
Lihat hasil 
yes
yes
yes
yes

Empat baris if yang bernilai truthy: x < y (0 < 5), y (5 bukan nol), x or y (hasilnya 5, truthy), dan 'aul' in 'grault' (substring ditemukan). Empat lainnya falsy dan tidak mencetak apa pun.

Blok: mengelompokkan pernyataan & indentasi

Contoh sebelumnya hanya berisi satu pernyataan ketika syarat terpenuhi. Ada saatnya kita menginginkan lebih dari satu hal untuk dilakukan — misalnya “ketika cuaca cerah, saya akan berjalan-jalan di taman, mencuci baju, dan membersihkan halaman.” Ketika <statement> berisi lebih dari satu perintah, pendekatan yang umum dilakukan adalah menggabungkan beberapa perintah tersebut ke dalam satu compound statement atau blok.

Sebuah blok dianggap sebagai satu entitas: ketika syarat terpenuhi, semua pernyataan di dalam blok dijalankan; ketika syarat tidak terpenuhi, tidak satu pun pernyataan dalam blok yang dijalankan.

Indentasi mendefinisikan blok (off-side rule)

Python mengikuti aturan yang dikenal sebagai off-side rule, yang diberi nama oleh seorang computer scientist asal Inggris bernama Peter J. Landin. Pada Python, indentasi punya makna penting yang digunakan untuk mendefinisikan compound statement atau blok: pernyataan-pernyataan yang berada pada level indent yang sama merupakan bagian dari blok yang sama.

if <expr>:
    <statement>
    <statement>
    ...
    <statement>
<following_statement>
Catatan: notasi lagi, bukan kode yang dijalankan — semua <statement> ada pada level indent yang sama (satu blok), sedangkan <following_statement> kembali ke level indent if sehingga selalu dijalankan, terlepas dari <expr> benar atau salah.

Tebak dulu, lalu klik untuk lihat hasil

if 'foo' in ['bar', 'baz', 'qux']:
    print('Expression was true')
    print('Executing statement in suite')
    print('...')
    print('Done.')
print('After conditional')
Lihat hasil 
After conditional

'foo' in ['bar', 'baz', 'qux'] bernilai False, jadi seluruh blok berindentasi dilewati. print('After conditional') tetap dijalankan karena indentasinya sejajar dengan if, bukan bagian dari bloknya.

Blok juga bisa bersarang (nested) — sebuah if bisa berada di dalam blok if lain, selama level indentasinya konsisten:

Tebak dulu baris mana yang tereksekusi, lalu klik untuk lihat hasil

if 'foo' in ['foo', 'bar', 'baz']:
    print('Outer condition is true')

    if 10 > 20:
        print('Inner condition 1')

    print('Between inner conditions')

    if 10 < 20:
        print('Inner condition 2')

    print('End of outer condition')
print('After outer condition')
Lihat hasil 
Outer condition is true
Between inner conditions
Inner condition 2
End of outer condition
After outer condition

print('Inner condition 1') satu-satunya baris yang dilewati, karena 10 > 20 salah. Baris-baris lain berada di blok yang syaratnya terpenuhi (blok if luar) atau di luar blok mana pun (print('After outer condition')).

Klausul else dan elif

Ketika kita ingin melakukan suatu hal ketika syarat terpenuhi, dan melakukan hal lain ketika tidak terpenuhi, gunakan klausul else:

if <expr>:
    <statement(s)>
else:
    <statement(s)>
Catatan: notasi — kedua blok untuk pernyataan ketika <expr> bernilai benar atau salah didefinisikan lewat indentasi, sama seperti blok if sendiri.

Tebak dulu, lalu klik untuk lihat hasil (x = 20)

x = 20
if x < 50:
    print('(first suite)')
    print('x is small')
else:
    print('(second suite)')
    print('x is large')
Lihat hasil 
(first suite)
x is small

Tebak dulu, lalu klik untuk lihat hasil (x = 120, kode sama persis)

x = 120
if x < 50:
    print('(first suite)')
    print('x is small')
else:
    print('(second suite)')
    print('x is large')
Lihat hasil 
(second suite)
x is large

Untuk beberapa alternatif pilihan, gunakan satu atau lebih klausul elif. Python akan mengevaluasi setiap <expr> secara berurutan dan mengeksekusi <statement> milik <expr> pertama yang bernilai benar. Jika tidak ada yang benar dan klausul else terdefinisi, pernyataan dalam klausul tersebut yang dieksekusi. Klausul elif boleh sejumlah berapa pun; klausul else bersifat opsional, dan jika dipakai harus diletakkan di akhir.

if <expr>:
    <statement(s)>
elif <expr>:
    <statement(s)>
elif <expr>:
    <statement(s)>
    ...
else:
    <statement(s)>
Catatan pada slide asli: pada contoh elif di slide, kondisi kesetaraan ditulis sebagai if name = 'Fred': (tanda “=” tunggal, kemungkinan hasil rendering font pada slide untuk “==”). Dibaca apa adanya, = tunggal di dalam ekspresi if tidak valid secara sintaks di Python (penugasan tidak boleh muncul di dalam ekspresi) — jadi contoh-contoh berikut memakai ==, sesuai maksud aslinya untuk membandingkan nilai.

Tebak dulu, lalu klik untuk lihat hasil

name = 'Joe'
if name == 'Fred':
    print('Hello Fred')
elif name == 'Xander':
    print('Hello Xander')
elif name == 'Joe':
    print('Hello Joe')
elif name == 'Arnold':
    print('Hello Arnold')
else:
    print("I don't know who you are!")
Lihat hasil 
Hello Joe

Python berhenti pada klausul elif pertama yang benar (name == 'Joe') dan tidak lagi menguji sisanya.

Kode sama, tanpa klausul else — kali ini tidak ada yang cocok, tebak dulu lalu klik

name = 'Mike'
if name == 'Fred':
    print('Hello Fred')
elif name == 'Xander':
    print('Hello Xander')
elif name == 'Joe':
    print('Hello Joe')
elif name == 'Arnold':
    print('Hello Arnold')
print('Program selesai.')
Lihat hasil 
Program selesai.

Ketika klausul else tidak diikutkan dan semua kondisi bernilai salah, tidak ada blok if/elif yang dieksekusi — program cukup melanjutkan ke pernyataan berikutnya.

Pernyataan if dan elif menggunakan evaluasi yang mirip short-circuit evaluation pada operator and dan or: begitu satu <expr> ditemukan bernilai True, blok tersebut dieksekusi dan <expr> berikutnya tidak diuji sama sekali — bahkan tidak dievaluasi.

Tebak dulu apakah ini error, lalu klik untuk lihat hasil

if 'a' in 'bar':
    print('foo')
elif 1/0:
    print("This won't happen")
elif var:
    print("This won't either")
Lihat hasil 
foo

Tidak error, walau 1/0 dan variabel var yang tidak pernah didefinisikan muncul di baris berikutnya. Karena 'a' in 'bar' sudah benar, klausul elif 1/0: dan elif var: tidak pernah dievaluasi — kalau saja dievaluasi, baris pertama akan melempar ZeroDivisionError.

If statement dalam satu baris

Penulisan if statement dapat dilakukan pada satu baris. Bahkan lebih dari satu <statement> dapat dituliskan pada baris yang sama, dipisahkan dengan titik koma (;):

if <expr>: <statement>

if <expr>: <statement_1>; <statement_2>; ...; <statement_n>

Jika dituliskan pada baris yang sama, Python akan mengeksekusi semua <statement_1> ... <statement_n> jika <expr> bernilai True. Jika tidak, tidak ada yang dieksekusi.

Tebak dulu, lalu klik untuk lihat hasil

if 'f' in 'foo': print('1'); print('2'); print('3')
if 'z' in 'foo': print('1'); print('2'); print('3')
Lihat hasil 
1
2
3

Baris kedua tidak mencetak apa pun karena 'z' in 'foo' salah.

Multiple statements juga bisa diterapkan pada baris yang sama untuk klausul elif atau else:

Tebak dulu, lalu klik untuk lihat hasil (x = 2)

x = 2
if x == 1: print('foo'); print('bar'); print('baz')
elif x == 2: print('qux'); print('quux')
else: print('corge'); print('grault')
Lihat hasil 
qux
quux

Tebak dulu, lalu klik untuk lihat hasil (x = 3, kode sama persis)

x = 3
if x == 1: print('foo'); print('bar'); print('baz')
elif x == 2: print('qux'); print('quux')
else: print('corge'); print('grault')
Lihat hasil 
corge
grault

Penulisan satu baris atau menggunakan indent dapat dipilih sesuai kebutuhan dan preferensi — keduanya setara. Versi berindentasi dari contoh x = 3 di atas:

Tebak dulu, lalu klik untuk lihat hasil

x = 3
if x == 1:
    print('foo')
    print('bar')
    print('baz')
elif x == 2:
    print('qux')
    print('quux')
else:
    print('corge')
    print('grault')
Lihat hasil 
corge
grault

Hasil identik dengan versi satu baris di atas — hanya gaya penulisan yang berbeda.

Ekspresi bersyarat (ternary operator)

Dalam bentuk paling sederhana, syntax untuk ekspresi bersyarat dituliskan sebagai berikut. Syntax ini juga dikenal sebagai ternary operator:

<expr1> if <conditional_expr> else <expr2>

<conditional_expr> dievaluasi terlebih dahulu. Jika benar, <expr1> dieksekusi dan <expr2> tidak dievaluasi sama sekali. Jika salah, <expr2> dieksekusi dan <expr1> tidak dievaluasi.

Tebak dulu, lalu klik untuk lihat hasil

raining = False
print("Let's go to the", 'beach' if not raining else 'library')

raining = True
print("Let's go to the", 'beach' if not raining else 'library')

age = 12
s = 'minor' if age < 21 else 'adult'
print(s)

print('yes' if ('qux' in ['foo', 'bar', 'baz']) else 'no')
Lihat hasil 
Let's go to the beach
Let's go to the library
minor
no

Salah satu kegunaan ekspresi bersyarat yang paling umum adalah untuk penugasan variabel — sebagai contoh, mencari nilai maksimum dari dua angka. Kedua cara berikut setara:

Tebak dulu, lalu klik untuk lihat hasil

a = 3
b = 7

# Cara 1: if dan else statement
if a > b:
    m = a
else:
    m = b
print(m)

# Cara 2: ekspresi bersyarat (ternary)
m = a if a > b else b
print(m)
Lihat hasil 
7
7

Prioritas operator

Operator + terikat lebih erat (mempunyai prioritas lebih tinggi) daripada ekspresi bersyarat:

Tebak dulu, lalu klik untuk lihat hasil

x = y = 40

z = 1 + x if x > y else y + 2
print(z)

z = (1 + x) if x > y else (y + 2)
print(z)

z = 1 + (x if x > y else y) + 2
print(z)
Lihat hasil 
42
42
43

x > y salah (keduanya 40), jadi dua baris pertama sama-sama mengevaluasi y + 2 = 42 — 1 + x if x > y else y + 2 otomatis terikat sebagai (1 + x) if (x > y) else (y + 2), persis seperti versi yang diberi tanda kurung eksplisit. Baris ketiga sengaja mengurung ekspresi bersyaratnya lebih dulu (x if x > y else y, hasilnya y yaitu 40) sehingga 1 + 40 + 2 = 43.

Karena cabang yang tidak dipilih memang tidak pernah dievaluasi, ekspresi bersyarat bisa dipakai untuk menghindari error yang seharusnya muncul dari cabang yang tidak diambil:

Tebak dulu apakah ini error, lalu klik untuk lihat hasil

print('foo' if True else 1/0)
print(1/0 if False else 'bar')
Lihat hasil 
foo
bar

Tidak ada ZeroDivisionError sama sekali — pada baris pertama 1/0 berada di cabang else yang tidak diambil, dan pada baris kedua 1/0 berada di cabang if yang juga tidak diambil.

Ekspresi bersyarat juga bisa dirangkai (chained), sebagai alternatif dari struktur if/elif/else dengan banyak cabang:

Tebak dulu, lalu klik untuk lihat hasil (x = 3)

x = 3
s = ('foo' if (x == 1) else
     'bar' if (x == 2) else
     'baz' if (x == 3) else
     'qux' if (x == 4) else
     'quux')
print(s)
Lihat hasil 
baz

Sama seperti klausul elif, evaluasi berhenti begitu satu cabang cocok (x == 3) dan cabang setelahnya tidak diuji.

Pernyataan pass

Ada kalanya ketika suatu syarat dipenuhi, kita menginginkan Python untuk tidak melakukan apa-apa — atau dengan kata lain, blok tersebut memang harus kosong. Karena Python mendefinisikan blok lewat indentasi (bukan tanda kurung kurawal), sebuah if tanpa isi sama sekali bukan sintaks yang valid. Untuk kasus ini, gunakan pernyataan pass: sebuah no-op (tidak melakukan apa-apa) yang hanya berfungsi sebagai placeholder sintaksis agar blok tetap valid secara sintaks.

Salah — blok if kosong 
if True:

print('foo')

IndentationError: expected an indented block after 'if' statement on line 1 — setelah baris kosong, print('foo') berada pada level indent yang sama dengan if, jadi Python tidak menemukan satu pun pernyataan berindentasi untuk mengisi blok if.

Benar — diisi pass 
if True:
    pass

print('foo')

Hasil: foo. pass mengisi blok if tanpa melakukan apa-apa, sehingga sintaksnya valid; print('foo') sendiri berada di luar blok if (indentasinya sejajar dengan if), jadi selalu dijalankan terlepas dari isi blok if.

pass sering dipakai sebagai placeholder sementara saat kerangka program sedang ditulis — misalnya badan fungsi atau kelas yang isinya belum diputuskan — supaya kode tetap bisa dijalankan sebelum logikanya dilengkapi.
