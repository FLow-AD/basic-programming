Teknik Memformat String

Dua cara menyisipkan nilai ke dalam string: metode .format() dan formatted string literal (f-string) — beserta mini-language format_spec yang dipakai keduanya untuk mengatur lebar, perataan, dan presisi tampilan.

Metode String .format()

Bentuk umum dari .format():

Catatan: ini notasi, bukan kode yang bisa langsung dijalankan — <template>, <positional_argument(s)>, dan <keyword_argument(s)> adalah placeholder.
<template>.format(<positional_argument(s)>, <keyword_argument(s)>)

<template> berisi ruang yang dapat diganti nilainya, dituliskan dalam kurung kurawal ({ }), disebut replacement field. <positional_argument(s)> dan <keyword_argument(s)> merincikan nilai yang akan dimasukkan ke dalam <template>.

Contoh dasar

Tebak dulu, lalu klik untuk lihat hasil

print('{{ {0} }}'.format('foo'))
Lihat hasil 
{ foo }

Kurung kurawal ganda {{ dan }} adalah cara meng-escape kurung kurawal literal — keduanya dicetak sebagai { dan } tunggal, sedangkan {0} tetap menjadi replacement field yang diganti dengan argumen posisi ke-0.

Argumen posisi — tebak dulu, lalu klik untuk lihat hasil

print('{0} {1} cost ${2}'.format(6, 'bananas', 1.74))
Lihat hasil 
6 bananas cost $1.74

{0}, {1}, {2} diganti berurutan dengan argumen posisi pertama, kedua, dan ketiga dari .format().

Argumen keyword — nilai yang sama, ditulis dengan nama

print('{quantity} {item} cost ${price}'.format(
    quantity=6,
    item='bananas',
    price=1.74))
Lihat hasil 
6 bananas cost $1.74

Hasilnya identik dengan versi argumen posisi — bedanya replacement field mengacu ke nama keyword argument, bukan ke nomor urut.

Argumen posisi

Argumen posisi disisipkan ke dalam <template> dalam bentuk angka, seperti indeks pada list. Nomor yang sama boleh dipakai berulang kali, dan urutannya boleh ditulis bebas (tidak harus 0, 1, 2, ...):

print('{0}/{1}/{2}'.format('foo', 'bar', 'baz'))
print('{2}.{1}.{0}/{0}{0}.{1}{1}.{2}{2}'.format('foo', 'bar', 'baz'))
Lihat hasil 
foo/bar/baz
baz.bar.foo/foofoo.barbar.bazbaz

Indeks yang tidak ada — tebak dulu, lalu klik untuk lihat hasil

'{3}'.format('foo', 'bar', 'baz')
Lihat hasil 
IndexError: Replacement index 3 out of range for positional args tuple

Hanya ada 3 argumen posisi (indeks 0, 1, 2) — indeks 3 tidak ada.

Sejak Python ≥ 3.1

Kurung kurawal boleh dikosongkan ({}); Python akan menomorinya secara otomatis mulai dari 0, sesuai urutan penulisan replacement field — bukan urutan argumen di .format().

print('{}/{}/{}'.format('foo', 'bar', 'baz'))
Lihat hasil 
foo/bar/baz

Penomoran otomatis ini punya dua batasan penting:

Field lebih banyak dari argumen 
'{}{}{}{}'.format('foo','bar','baz')

IndexError: Replacement index 3 out of range for positional args tuple — 4 field otomatis (indeks 0–3) tapi cuma 3 argumen.

Argumen lebih banyak dari field 
print('{}{}'.format('foo', 'bar', 'baz'))

Hasilnya foobar — argumen ketiga ('baz') sah-sah saja diberikan, tapi tidak pernah dipakai karena tidak ada field ketiga.

Mencampur manual & otomatis 
'{1}{}{0}'.format('foo','bar','baz')

ValueError: cannot switch from manual field specification to automatic field numbering — sekali memakai indeks manual ({1}, {0}) dalam satu template, field otomatis ({}) tidak boleh dicampur di situ.

Keyword arguments

Keyword arguments disisipkan pada template untuk menggantikan nilai pada ruang dengan nama yang sama:

print('{x}/{y}/{z}'.format(x='foo', y='bar', z='baz'))
Lihat hasil 
foo/bar/baz

Nama yang tidak diberikan — tebak dulu, lalu klik untuk lihat hasil

'{x}/{y}/{w}'.format(x='foo', y='bar', z='baz')
Lihat hasil 
KeyError: 'w'

Field {w} minta keyword argument bernama w, tapi yang diberikan cuma x, y, z.

Perbedaan penting antara keduanya: untuk argumen posisi, urutan penulisan argumen menentukan hasil; untuk keyword argument, urutan penulisan di pemanggilan .format() tidak berpengaruh — yang menentukan adalah namanya:

print('{0}/{1}/{2}'.format('foo', 'bar', 'baz'))
print('{0}/{1}/{2}'.format('bar', 'baz', 'foo'))
print('{x}/{y}/{z}'.format(x='foo', y='bar', z='baz'))
print('{x}/{y}/{z}'.format(y='bar', z='baz', x='foo'))
Lihat hasil 
foo/bar/baz
bar/baz/foo
foo/bar/baz
foo/bar/baz

Baris 2 berubah karena argumen posisinya ditukar urutan; baris 3 dan 4 tetap sama meskipun urutan penulisan x=, y=, z= di baris 4 diacak.

Kombinasi posisi & keyword

Jika ingin menggunakan keyword argument dan positional argument sekaligus, positional argument harus dituliskan lebih dulu:

print('{0}{x}{1}'.format('foo', 'bar', x='baz'))
Lihat hasil 
foobazbar
Keyword sebelum positional — ini bukan aturan .format(), tapi aturan sintaks Python untuk pemanggilan fungsi apa pun 
'{0}{x}{1}'.format('foo', x='baz', 'bar')

SyntaxError: positional argument follows keyword argument — begitu satu argumen ditulis pakai nama=, semua argumen posisi setelahnya juga dianggap melanggar urutan, walau di sini niatnya menyisipkan satu argumen posisi terakhir.

Variabel juga bisa dipakai sebagai argumen, dicampur posisi dan keyword seperti biasa:

x = 'foo'
y = 'bar'
z = 'baz'
print('{0}/{1}/{s}'.format(x, y, s=z))
Lihat hasil 
foo/bar/baz

Simple replacement fields

<template> berisi replacement field yang terdiri atas 3 komponen:

{[<name>][!<conversion>][:<format_spec>]}
Referensi: komponen replacement field
KomponenArti
<name>Menentukan sumber nilai yang akan diformat (indeks posisi atau nama keyword).
<conversion>Menentukan fungsi bawaan Python mana yang dipakai untuk mengonversi nilainya menjadi string.
<format_spec>Merincikan detail lebih lanjut tentang bagaimana nilai tersebut ditampilkan.

Komponen <conversion>

Python dapat memformat sebuah objek sebagai string dengan tiga fungsi: str(), repr(), dan ascii(), dipanggil lewat !s, !r, !a:

print('{0!s}'.format(42))
print('{0!r}'.format(42))
print('{0!a}'.format(42))
Lihat hasil 
42
42
42

Untuk integer, ketiga fungsi ini kebetulan menghasilkan string yang sama persis.

Supaya perbedaannya terlihat, coba pada string

print('{0!s}'.format('hi'))
print('{0!r}'.format('hi'))
Lihat hasil 
hi
'hi'

!s (str()) mencetak string apa adanya; !r (repr()) menyertakan tanda kutipnya — representasi yang bisa (idealnya) ditulis ulang sebagai kode Python.

Komponen <format_spec>

Bentuk umum dari <format_spec>:

:[[<fill>]<align>][<sign>][#][0][<width>][<group>][.<prec>][<type>]
Referensi: subkomponen format_spec
SubkomponenEfek
:Memisahkan <format_spec> dari sisa replacement field.
<fill>Karakter yang dipakai untuk mengisi ruang kosong ketika nilai belum memenuhi seluruh lebar field.
<align>Perataan nilai ketika nilai belum memenuhi seluruh lebar field (< kiri, > kanan, ^ tengah).
<sign>Mengatur apakah tanda (+/−) disertakan di depan nilai numerik.
#Memilih bentuk keluaran alternatif untuk tipe presentasi tertentu.
0Nilai diisi angka nol di sebelah kiri, bukan spasi ASCII.
<width>Lebar minimum dari keluaran.
<group>Karakter pengelompokan untuk keluaran numerik (mis. pemisah ribuan).
.<prec>Jumlah digit di belakang titik desimal untuk tipe floating-point, atau lebar keluaran maksimum untuk tipe string.
<type>Tipe presentasi — jenis konversi yang dilakukan pada argumen terkait.
Referensi: subkomponen <type>
ValuePresentation Type
bBinary integer
cSingle character
dDecimal integer
e atau EExponential
f atau FFloating point
g atau GFloating point atau Exponential
oOctal integer
sString
x atau XHexadecimal integer
%Percentage

<format_spec> menggantikan gaya lama %-formatting dengan hasil yang setara:

print('%d' % 42)
print('{:d}'.format(42))
print('%f' % 2.1)
print('{:f}'.format(2.1))
print('%s' % 'foobar')
print('{:s}'.format('foobar'))
print('%x' % 31)
print('{:x}'.format(31))
Lihat hasil 
42
42
2.100000
2.100000
foobar
foobar
1f
1f

Menerapkan format_spec

Kombinasi <fill>, <align>, <width>, <sign>, <group>, .<prec>, dan <type> dari tabel referensi di atas, dipraktikkan:

Tebak dulu, lalu klik untuk lihat hasil (tanda [ ] hanya penanda batas, bukan bagian dari hasil)

print('[{:10}]'.format('test'))
print('[{:>10}]'.format('test'))
print('[{:*^10}]'.format('test'))
print('[{:05d}]'.format(42))
print('{:+d}'.format(42))
print('{:,}'.format(1234567))
print('{:,.2f}'.format(1234567.891))
print('{:.1%}'.format(0.25))
print('{:#b}'.format(10))
Lihat hasil 
[test      ]
[      test]
[***test***]
[00042]
+42
1,234,567
1,234,567.89
25.0%
0b1010

Baris 1: string rata kiri (default) dengan lebar 10, diisi spasi. Baris 2: > memaksa rata kanan. Baris 3: *^ memakai * sebagai fill dan rata tengah. Baris 4: 0 mengisi angka dengan nol di kiri hingga lebar 5. Baris 5: + selalu menampilkan tanda. Baris 6–7: , menyisipkan pemisah ribuan, bisa digabung dengan .2f untuk presisi. Baris 8: tipe % otomatis mengalikan 100 dan menambahkan tanda persen. Baris 9: #b menambahkan prefiks 0b di depan bentuk binernya.

Nested replacement fields

<name> mengindikasikan argumen yang disisipkan, dapat berupa angka (indeks) untuk positional arguments atau kata kunci untuk keyword argument. Kalau argumen itu sendiri berupa list, elemennya bisa diakses langsung di dalam replacement field dengan menuliskan indeksnya — inilah yang disebut nested replacement:

x, y, z = 1, 2, 3
a = ['foo', 'bar', 'baz']
print('{0[0]}, {0[2]}'.format(a))
print('{my_list[0]}, {my_list[2]}'.format(my_list=a))
Lihat hasil 
foo, baz
foo, baz

{0[0]} berarti: ambil argumen posisi ke-0 (yaitu a), lalu indeks [0]-nya. {my_list[2]} berarti: ambil keyword argument my_list, lalu indeks [2]-nya. Perhatikan tidak ada tanda kutip di sekitar 0 maupun 2 di dalam kurung siku — berbeda dari indexing Python biasa.

Formatted String Literal (f-string)

Cara kedua untuk memformat string: awali literal string dengan huruf f atau F, lalu tulis ekspresi Python langsung di dalam kurung kurawal — tidak perlu memanggil .format() secara terpisah.

Syntax

name = 'Andi'
age = 20
print(f'Nama saya {name}, umur {age} tahun.')
Lihat hasil 
Nama saya Andi, umur 20 tahun.

Bagian di dalam { } bukan cuma nama variabel — boleh ekspresi Python apa saja: operasi aritmetika, pemanggilan method, bahkan pemanggilan fungsi:

print(f'{3 + 4}')
a = ['foo', 'bar', 'baz']
print(f'{a[0].upper()}')
Lihat hasil 
7
FOO

Pengaturan format f-string

f-string memakai <format_spec> dan <conversion> yang persis sama seperti pada .format(), ditulis setelah ekspresinya:

print(f'{3.14159:.2f}')
print(f'{1234567:,}')
print(f'{42!r}')
Lihat hasil 
3.14
1,234,567
42

Digabung dalam satu contoh

harga = 24990.5
print(f'Total: Rp{harga:,.2f}')
Lihat hasil 
Total: Rp24,990.50

Bonus yang tidak dimiliki .format(): akhiri sebuah field dengan = untuk mencetak teks ekspresinya sekaligus nilainya — berguna untuk debugging cepat tanpa menulis ulang nama variabelnya di dalam string:

age = 20
print(f'{age=}')
x = 5
y = 3
print(f'{x=}, {y=}, {x + y = }')
Lihat hasil 
age=20
x=5, y=3, x + y = 8

Spasi di sekitar ekspresi (seperti pada x + y = ) ikut dicetak apa adanya — itu sebabnya hasilnya x + y = 8, bukan x+y=8.

Batasan

Bagian ekspresi di dalam { } historisnya (sebelum Python 3.12) punya dua batasan sintaks yang sering mengejutkan pemula:

Backslash di dalam ekspresi 
print(f'{"a\nb"}')

SyntaxError: f-string expression part cannot include a backslash — karakter \ (termasuk untuk escape sequence seperti \n) tidak boleh muncul di dalam kurung kurawal { }.

Kutip yang sama dengan pembatas f-string 
print(f'{'hello'}')

SyntaxError: f-string: expecting '}' — Python mengira { sudah ditutup begitu bertemu tanda kutip tunggal, karena f-string-nya sendiri juga dibatasi tanda kutip tunggal. Solusinya (sebelum 3.12): pakai tanda kutip yang berbeda, misalnya f"{'hello'}".

Diverifikasi untuk versi Python ini

Kedua contoh di atas benar-benar menghasilkan SyntaxError pada Python 3.11 (versi yang dipakai untuk menjalankan dan memvalidasi seluruh kode di situs ini). Sejak Python 3.12 (PEP 701), kedua batasan ini dihapus — backslash dan tanda kutip yang sama boleh dipakai bebas di dalam ekspresi f-string. Ini dicek langsung dengan menjalankan kode yang sama di interpreter Python 3.12: keduanya berhasil dan tidak lagi menghasilkan error.
