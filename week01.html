Apa itu pemrograman?

Programming adalah usaha membuat komputer melakukan dan menyelesaikan sebuah tugas spesifik tanpa melakukan kesalahan. Komputer sendiri tidak pintar — ia menjadi berguna karena diprogram oleh manusia.

Komputer hanya benar-benar mengerti kode mesin: rangkaian angka 1 dan 0 (biner). Bahasa pemrograman seperti Python berperan sebagai penerjemah antara cara berpikir manusia dan bahasa yang dimengerti komputer, sehingga menulis program jauh lebih praktis daripada menulis biner langsung.

Setiap bahasa punya aturan penulisannya sendiri (syntax). Melanggar aturan ini menghasilkan error — sama seperti kalimat “Let’s eat, Grandma!” berubah makna total tanpa tanda koma.

Kenapa Python?

Python dipilih karena mudah dipelajari, high-level (tidak perlu mengelola memori secara manual), gratis dan open source, portable ke berbagai platform, serta punya standard library yang luas (filosofi “batteries included”).

Python juga populer sebagai “bahasa perekat”: mudah diintegrasikan dengan C, C++, dan FORTRAN, sehingga riset dan prototipe (biasanya di MATLAB atau R) bisa langsung ditransfer menjadi sistem produksi tanpa berpindah bahasa. Sebagian besar AI, machine learning, dan big data memakai Python.

Kelebihan

Sederhana, mudah dibaca, extensible, embeddable, komunitas besar, cocok untuk web, data, otomasi, hingga AI.

Batasan

Interpreted, sehingga umumnya lebih lambat dari bahasa compiled seperti C/C++ (bisa diatasi dengan Cython). Kurang ideal untuk komputasi paralel dan multithread yang berat.

Gunakan Python 3.x. Python 2.7 sudah tidak didukung sejak 2020 dan tidak kompatibel dengan Python 3.x.

Instalasi

  1. Python — unduh dari python.org/downloads, pilih versi 3.10 ke atas. Saat menjalankan installer, centang “Add python.exe to PATH” sebelum klik “Install Now”.
  2. Verifikasi — buka Command Prompt (cmd) dan jalankan python --version. Jika muncul nomor versi, instalasi dan PATH sudah benar.
  3. VS Code — unduh dari code.visualstudio.com, lalu saat instalasi centang keempat opsi tambahan (desktop icon, dua opsi “Open with Code”, dan Add to PATH).
  4. Ekstensi Python — di VS Code, buka Extensions (Ctrl+Shift+X), cari “Python”, pasang ekstensi resmi dari Microsoft (ms-python.python).
  5. Hubungkan interpreter — Ctrl+Shift+P → ketik “Python: Select Interpreter” → pilih Python yang baru diinstal.

pip

pip install <nama-paket> memasang paket, pip uninstall <nama-paket> mencopotnya, pip list menampilkan paket yang terpasang, dan pip install --upgrade pip memperbarui pip itu sendiri.

Diperbaiki dari slide asli: pip search pernah ada tapi dinonaktifkan PyPI sejak 2021 karena beban server, jadi perintah ini sekarang gagal. Cari paket langsung di pypi.org.

Jupyter Notebook & Google Colab

Jupyter Notebook adalah interactive computing environment: kode, teks naratif, dan hasil (termasuk plot) berdampingan dalam satu dokumen .ipynb. Sebuah notebook terdiri dari sel-sel: code cells untuk kode, dan markdown cells untuk teks berformat (Markdown adalah superset dari HTML yang ditulis lebih ringkas, misalnya ## Judul untuk heading level 2).

Jalankan dari terminal dengan python -m notebook, atau gunakan Google Colab (colab.research.google.com) — versi Jupyter Notebook gratis yang berjalan sepenuhnya di cloud Google, tanpa setup, dan menyediakan GPU gratis. File Colab tersimpan di Google Drive, folder Colab Notebooks.

Di Colab, perintah shell apa pun bisa dijalankan dengan awalan ! (misalnya !pip install namapaket atau !ls), dan Google Drive dihubungkan dengan:

from google.colab import drive
drive.mount('/content/drive/')

Tipe data dasar

Python punya empat tipe data dasar: Numeric (angka), String (teks), Boolean (logika), dan Function (untuk mentransformasi data-data di atas). Cek tipe data apa pun dengan type(...).

Numeric — integer

Python 3 tidak membatasi seberapa besar nilai integer, hanya dibatasi memori komputer. Selain basis 10 (desimal), integer bisa ditulis dengan prefiks basis lain: 0b/0B untuk biner, 0o/0O untuk oktal, 0x/0X untuk heksadesimal — semuanya tetap dikategorikan bertipe int.

Tebak dulu, lalu klik untuk lihat hasil

print(0o10)
print(0x10)
print(0b10)
print(type(0o10))
Lihat hasil 
8
16
2
<class 'int'>

Numeric — floating point

Tipe float merepresentasikan angka desimal, memakai standar IEEE 754 “double precision” 64-bit. Karakter e/E diikuti integer menyatakan notasi ilmiah.

Tebak dulu, lalu klik untuk lihat hasil

print(4.2)
print(.4e7)
print(4.2e-4)
print(1.79e308)
print(1.8e308)
print(5e-324)
Lihat hasil 
4.2
4000000.0
0.00042
1.79e+308
inf
5e-324

Melebihi batas atas float menghasilkan inf (infinity), bukan error.

Diperbaiki dari slide asli: nilai float maksimum yang bisa diproses Python sekitar 1.8 × 10308 (bukan 10208), dan nilai positif terkecil sekitar 5.0 × 10−324. Sesuai docs.python.org dan diverifikasi langsung dengan menjalankan kodenya.

Numeric — bilangan kompleks

Ditulis <bagian riil>+<bagian imajiner>j.

Tebak dulu, lalu klik untuk lihat hasil

z = 2 + 3j
print(z, type(z))
print(z.conjugate())
Lihat hasil 
(2+3j) <class 'complex'>
(2-3j)
Diperbaiki dari slide asli: c.conjugate() mengembalikan konjugat dari bilangan kompleks c (bagian imajiner dibalik tandanya), bukan “menambahkan” bilangan kompleks.

String

String ditulis dengan tanda petik tunggal atau ganda — keduanya setara. Karakter \ membuat escape sequence untuk karakter khusus. String diawali prefiks r/R (raw string) menonaktifkan escape sequence, dan petik tiga (''' atau """) memungkinkan string multi-baris tanpa perlu meng-escape petik di dalamnya.

Tebak dulu, lalu klik untuk lihat hasil

print('This string contains a single quote (\') character.')
print('foo\tbar')
print('foo\\bar')
r = r'foo\nbar'
print(r)
Lihat hasil 
This string contains a single quote (') character.
foo	bar
foo\bar
foo\nbar

Variabel

Variabel di Python tidak perlu dideklarasikan tipenya di awal — cukup ditugaskan (assign) sebuah nilai. Tipe variabel juga bisa berubah seiring waktu.

Tebak dulu, lalu klik untuk lihat hasil

n = 300
print(n)
a = b = c = 300
print(a, b, c)
var = 23.5
print(type(var))
var = "Now I'm a string"
print(type(var))
Lihat hasil 
300
300 300 300
<class 'float'>
<class 'str'>

a = b = c = 300 adalah chained assignment: ketiga variabel menunjuk ke nilai yang sama.

Operator penugasan majemuk (augmented assignment) menyingkat x = x <op> y menjadi x <op>= y: +=, -=, *=, /=, %=, **=, //=.

Tebak dulu, lalu klik untuk lihat hasil

x = 10
x += 5
x **= 2
print(x)
Lihat hasil 
225

10 + 5 = 15, lalu 15 dipangkatkan 2 menjadi 225.

Aturan penamaan

  • Boleh memakai huruf besar/kecil, digit, dan garis bawah (_); karakter pertama tidak boleh berupa digit.
  • 31 kata berikut adalah keyword dan tidak boleh dipakai sebagai nama variabel: False None True and as assert break class continue def del elif else except finally for from global if import in is lambda nonlocal not or pass raise return try while with yield.

Tebak dulu, lalu klik untuk lihat hasil

for = 3
Lihat hasil 
SyntaxError: invalid syntax

for adalah keyword, jadi tidak bisa dipakai sebagai nama variabel.

Python Style Rules

Ringkasan PEP 8 dan Google Python Style Guide, supaya kode kelas ini konsisten dan mudah dibaca satu sama lain.

Satu pernyataan per baris

Yes 
i = 5
print(i)
No 
i = 5; print(i)

Jangan mengakhiri baris dengan titik koma, dan jangan gunakan titik koma untuk menggabung dua pernyataan dalam satu baris. Panjang baris maksimum 80 karakter; jangan gunakan backslash (\) untuk melanjutkan baris — andalkan tanda kurung.

Tanda kurung

Yes 
if foo:
    bar()

while x:
    x = bar()

return foo
No 
if (x):
    bar()

if not(x):
    bar()

return (foo)

Jangan gunakan tanda kurung pada pernyataan return atau kondisional kecuali untuk menandai lanjutan baris. Tanda kurung tetap dipakai untuk tuple.

Indentasi dan baris kosong

  • Python memakai indentasi (bukan { }) untuk blok kode — 4 spasi per level, jangan campur tab dan spasi.
  • Dua baris kosong di antara definisi tingkat atas (fungsi/kelas), satu baris kosong di antara definisi metode.

Whitespace

Yes 
spam(ham[1], {eggs: 2}, [])
if x == 4:
    print(x, y)
x, y = y, x
No 
spam( ham[1], { eggs: 2 }, [ ] )
if x == 4 :
    print(x , y)
x , y = y , x

Tidak ada spasi tepat di dalam () [] {}, tidak ada spasi sebelum koma/titik dua, dan tidak ada spasi sebelum kurung buka untuk pemanggilan fungsi atau indexing. Beri satu spasi di sekitar operator penugasan dan perbandingan — kecuali untuk keyword argument: def complex(real, imag=0.0):, bukan imag = 0.0.

String

  • Konsisten memilih ' atau " di seluruh berkas.
  • Gunakan .format() (atau f-string) untuk memformat string, terutama saat menggabungkan banyak nilai; + cukup untuk penggabungan sederhana.
  • Hindari mengakumulasi string dengan += di dalam loop — string bersifat immutable, sehingga tiap += membuat objek sementara baru. Kumpulkan potongan dalam list, lalu ''.join(...) sekali di akhir.

Import, pernyataan, dan nama

  • Satu modul per baris import, diletakkan di paling atas berkas, dikelompokkan dari standard library → pihak ketiga → modul milik proyek sendiri.
  • Hindari nama satu karakter kecuali untuk counter/iterator, dan hindari garis strip (-) dalam nama modul.
  • Setiap berkas yang dijalankan langsung sebaiknya memakai penjaga __main__:
def main():
    ...


if __name__ == '__main__':
    main()
